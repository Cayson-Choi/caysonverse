## 직접 만든 것

- 십자고상: 공개된 십자고상 3D 스캔은 로그인 없이 받을 곳이 없어서(아래 "더 좋은 원본"), Met 466395 사진으로 사진-부조를 만들었어요
  (`make_crucifix_relief.py` → `build_relief.py` → `process_statue.py` "photo"). 앞(장의자)에서는 실제 채색 목조 십자고상 사진 그대로 보이고, 옆에서는 두께가 있는 부조예요.
  Blender로 몸을 직접 조각해 SMK KAS1648 머리 스캔과 합친 시안(`build_corpus.py`)은 마네킹처럼 보여서 **버렸어요**(파일은 기록으로만 남김).
- 교회 나무 십자가, 십자가의 길 14처 판(참나무 판 + 작은 십자가 + 청동 로마 숫자 I–XIV), 장미창 돌 트레이서리, 창의 납 테·철 띠, 탱화 비단 회장과 붉은 틀:
  `build_props.py`로 직접 제작. 나무·돌·철 질감은 저장소 PBR 라이브러리(CC0, feat/pbr-library)의 `wood_oak`, `stone_ashlar`(NEW), `cast_iron`, `dancheong_wood`(NEW)를 재질 이름으로 가리켜요.
- 대리석·금박·청동 표면: 스캔 원본 고해상도에서 Blender 절차적 재질을 구운 것(직접 제작).
