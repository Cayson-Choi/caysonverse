# 21차 · 코

20차(28b71402)의 본존불 GLB 두 개에서 코 전체를 다시 만들었다. 제작은 `node/buddha_nose21.mjs`이고, `buddha_pack.mjs ... --alar-balls-from <20차 GLB 폴더>`로 실행한다.

## 바뀐 것

- 코끝 공과 양쪽 콧방울 공을 매끈한 입체(타원체 합성)로 다시 빚었다. 콧구멍은 작은 타원으로, 원본 정면 사진의 위치에 맞췄다.
- 코의 금박 명암은 원본 사진을 ChatGPT로 선명하게 다시 그린 그림을 원본 정면 카메라에 정합해 투영했다. 색은 볼의 금박을 그대로 쓰고 밝기만 가져온다. 그늘은 원본 금박처럼 어두울수록 붉은 갈색이 된다.
- 콧등과 코 옆의 기존 삼각형(형상과 법선 그대로)을 코 재질로 옮겨 같은 방식으로 칠했다. 바깥 테두리는 기존 색에 고정하고 안쪽으로 부드럽게 바뀐다.
- 콧방울 바깥 볼의 얼룩(폰의 녹색 띠 포함)과 코 둘레 경계를 정리했다.

## 재현

선명화본 그림은 원본 사진을 바탕으로 한 것이라 저장소에 넣지 않는다. `NOSE_SHARP_REF`에 정합한 그림 두 장(`redraw-registered-head-front.png`, `redraw-registered-side.png`)이 있는 비공개 폴더를 지정해야 빌드된다.

## 확인

- 대웅전 걷기 e2e: PC 21/21, 폰 21/21 (23차까지 누적한 GLB로 확인).
- 사찰 GLB 검사 `lotTempleGlb.test.ts`: 10/10.
- 이 폴더의 그림은 모델만 찍은 렌더다. 원본과 나란히 놓은 비교판은 저장소 밖 인계 폴더에 있다.
