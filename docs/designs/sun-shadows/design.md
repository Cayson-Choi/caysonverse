# 실제 해 위치와 해를 따라가는 그림자 (2026-11-16)

발주자 요청: "해가 한국 시간에 맞춰서 위치하도록 해. 그리고 광장에 초승달 형상의 밝기와 그림자 뿐만 아니라 다른 것들도
하늘의 해의 위치에 따라서 그림자가 제대로 형성되도록 해."

## 1. 지금 구조 (조사 결과)

- 해의 위치는 이미 실제 시각으로 계산하고 있었다: `shared/src/village/sunClock.ts` (NOAA/Meeus, 36.5° N 127.8° E, 대기 굴절
  포함, KASI 서울 일출·일몰 ±2분 단위 시험). 하늘 색·황금빛·밤 전환(`dayNightBlend.ts`)도 시각이 아니라 해의 고도로 섞는다.
  북 = -z, 동 = +x (HUD 나침반 `compass.ts`와 같은 축). 해무리 스프라이트도 실제 방향에 있다.
  → 이번에 서울 남중 고도(춘분·하지·추분·동지·11/16, 적위로 계산한 값 ±0.3°)와 남중 방위(정남 ±1°), 아침/오후 방위 시험을 더했다.
- 마을 모델(`village.glb`)은 **조명을 받지 않는 재질 + 구운 라이트맵**이다. 낮 라이트맵에는 해(방위 70°, 고도 20°, 4.8 W/m²,
  `look.json`)의 직사광과 그 그림자가 **고정된 아침 한 장**으로 구워져 있다. 그래서 건물·나무·벤치·가로등 그림자는 해가 움직여도
  그대로였다. 장면의 방향광은 실제 해를 따라갔지만(최소 14°), 아바타 그림자만 받았다(평평한 투명 판 `ShadowFloor`).
- 광장 초승달은 노멀이 있는 유일한 메시로, 구운 빛을 노멀의 구면조화(SH)로 맞춘 프로브로 밝힌다(역시 고정된 해).
- 나무는 이제 런타임 식생(veg3d)이다. 라이트맵에 구운 나무 그림자는 예전 카드 나무의 것.

## 2. 방법

### 2.1 빛의 식 (라이트맵 단위 = L / 2)

낮 라이트맵 텍셀 `d`에서 구운 해의 직사광을 빼고, 실제 해의 직사광을 실시간 그림자와 함께 더한다.

```
d' = max(d − Kb·max(0, n·lb)·B, 0.3 d) · sky  +  K·c(t)·max(0, n·l(t))^0.65 · S
```

- `Kb = 0.73 × lin(#FFD6A8)`: 구운 해의 직사광(n·l = 1). Blender에서 해만 따로 구워(`bake_village.py --sunonly`) 잰 값
  (평평한 땅 최빈값 0.36 L ÷ sin 20°, 해를 마주한 벽 0.96 L → 채널 R 0.73 맵 단위).
- `B`: 구운 해 방향의 가시도. **라이트맵 UV 공간 마스크**를 불러올 때 한 번 만든다(`bakedSunMask.ts`, 데스크톱 11-15 ms /
  휴대폰 4배 스로틀 14-58 ms): 마을을 64 m 타일로 나눠 타일마다 구운 해 방향 깊이맵(2048²)을 그리고, 라이트맵 UV로 펼친
  패스에서 텍셀 면적을 4×4로 평균, 섬 여백 8번 팽창. 구운 모델 그대로(로더의 원본: 예전 카드 나무 줄기, 광장 느티나무)를 쓴다.
  예전 카드 나무의 잎(M_leaf_*)은 뺀다: 실제 라이트맵에는 잎 그림자가 거의 없는데 깊이맵에선 왕관만 한 얼룩이 됐다(확인함).
- `n`: 지금 glb에는 노멀이 없어 화면 미분으로 면 노멀을 구한다(건물·땅은 평면이라 정확). 다음 굽기부터 노멀이 오면 그것을 쓴다.
- `S`: 실시간 그림자(2.2). `K·c(t)`: 실제 해의 세기·색(구운 해와 같은 단위, 낮을수록 약해지고 해가 지면 0).
- 맑은 날의 대비: 구운 하늘(HDRI 2.2 대 해 4.8)이 밝은 광장을 해만큼 밝혀서 그림자가 1.3배밖에 안 어두웠다. 해가 높을 때
  하늘 몫 × 0.68(`SKY_SHARE`), 실제 해 × 1.45(`SUN_GAIN`), n·l^0.65(`NL_POWER`, 저녁의 긴 그림자가 보이게). 해가 지면 1로.
- 노출 적응(`sunAdaptation`): 해가 구운 해(20°)보다 높아 땅이 더 밝아지는 만큼 노출을 내린다(지수 0.85, 최소 0.62배, 올리지는
  않는다). 밝은 광장이 톤 곡선 어깨에서 하얗게 날리며 그림자까지 지워지던 문제.
- 0.3 d 바닥: 마스크가 구운 그림자와 어긋나는 가장자리에서 검은 줄이 생기지 않게. 마스크 바깥(마을 밖 멀리)은 구운 그대로.

**다음 굽기 이후**(라이트맵에 해의 직사광이 없고 glb `asset.extras.cvLightmapSun = "live"`): 빼기와 마스크를 건너뛰고
더하기만 한다. 같은 셰이더, 유니폼 하나로 갈린다(`VillageModel` → `LiveSunShadows` `lightmapSun`).

초승달은 프로브 값에서 같은 식(구운 항은 매끈한 n·lb, 실시간 항은 실제 노멀과 그림자). 런타임 나무는 정점 음영의 해 몫을
실시간 그림자만큼 빼고(1탭), 음영 방향도 실제 해로. 밤 라이트맵(구운 달)은 그대로, 실시간 그림자만 달빛 쪽으로 35% 어둡힌다.

### 2.2 실시간 그림자맵

| | 화려하게, PC | 화려하게, 휴대폰(직접 고른 경우) | 가볍게 (휴대폰 기본) |
|---|---|---|---|
| 가까운 단 | 장면의 해 방향광 그림자맵 2048², 카메라가 보는 곳 반경 32 m, **매 프레임**, 마을+나무+아바타+버스 | 1024², 반경 24 m, 매 프레임, **움직이는 것만**(아바타, 버스) | 없음 (아바타는 원형 블롭) |
| 먼 단 | 마을 전체(약 490×270 m) 2048², 해가 0.15° 움직이면 다시 | 같음, 0.25° | 같음, 0.25° |

- 먼 단은 맵 두 장(더블 버퍼): 새 방향은 예비 맵에 **한 프레임에 한 조각씩**(고 2, 휴대폰·저 8조각) 그리고 다 그리면 바꿔 낀다
  → 걸을 때도, 해가 움직일 때도 끊김·반쯤 그려진 프레임 없음.
- 가까운 단 상자는 빛 공간 텍셀 단위로 맞춰(snap) 걸을 때 그림자가 떨리지 않고, 방향은 정해진 각도를 넘을 때만 바꾼다.
- 상자는 해 쪽으로 400 m까지 깊이를 잡아 낮은 해의 긴 그림자도 들어온다. 그림자 방향 고도는 2° 아래로 내리지 않는다.
- 마을 재질은 three의 조명 시스템을 쓰지 않으므로 깊이 텍스처(`sampler2DShadow`)와 행렬을 직접 유니폼으로 읽는다
  (5탭 하드웨어 PCF, 노멀 오프셋 + 깊이 바이어스). 아직 맵이 없을 때도 1×1 비교 깊이 텍스처를 묶어 둔다(ANGLE의
  "Mismatch between texture format and sampler type" 방지). 아바타 등 조명 재질은 three 그대로.
- 마을에서는 `ShadowFloor`(평평한 판)를 끈다: 땅·벽·지붕이 그림자를 직접 받는다. `?sun=off`(DEV)는 예전 그대로.

### 2.3 해 방향

`dayNightBlend.stateFor`: `shadowDir` = 해가 떠 있으면(고도 > −2°) 실제 해(최소 2°), 아니면 구운 달. 장면의 방향광도
같은 방향을 쓴다(아바타 그림자도 같은 쪽).

## 3. 성능 (이 PC, 헤드리스 크롬 + 실제 GPU, 정오, 같은 자리. off = `?sun=off`)

| | off 바쁜 시간/프레임 | on | 차이 |
|---|---|---|---|
| PC 화려하게, 정지 / 걷기 | 5.30 / 5.39 ms | 5.96 / 6.02 ms | +0.6 ms (60 fps 유지, p95 16.8) |

## 4. 다음 마을 굽기에서 할 일 (`bake_village.py`에 반영, git에는 `bake_village_sunsplit.patch`)

**지금은 다시 구울 수 없다**(W6 확인, 2026-11-16): 배포된 village.glb는 이 PC에 없는 집·카페 재건 스크립트("houses-m1")로
만들어졌고, 여기의 art/village 도구·work/*.blend는 11/3-11 것이라 build_village.py를 돌리면 집·카페가 되돌아간다.
그래서 위의 구현은 **지금 라이트맵만으로 완전히 동작한다**: 구운 해 마스크는 불러온 glb 자신(지금 배포된 집·카페 그대로)에서
게임이 만든다. 아래는 그 스크립트가 돌아온 뒤 다시 구울 때 좋아지는 것뿐이다(마스크가 못 잡는 가장자리 잔상·얇은 소품의
구운 그림자가 사라지고, 부드러운 노멀, 마스크 8 MB와 빌드 시간 없음).

1. `SUN_SPLIT = True`(기본): 해 램프만 켜고(하늘 세기 0, 발광 끔) DIRECT만 구워 낮 라이트맵에서 빼고 저장. 
   `work/village_lm_sun.png`도 남긴다. (`--keepsun`은 예전 방식.)
2. `export_normals=True`: 실시간 n·l을 부드러운 노멀로.
3. `patch_glb`가 `asset.extras.cvLightmapSun = "live"`와 구운 해 정보를 넣는다 → 게임이 자동으로 빼기·마스크를 건너뛴다.
4. 초승달 프로브(`fit_moon_probe.py`)를 해 없는 라이트맵에 다시 맞추고 `sunShadows.ts`의 `MOON_PROBE_HAS_SUN = false`.
5. 해가 바뀌면(look.json) `SUN_DIRECT_K`를 `--sunonly`로 다시 잰다.
6. `--sunonly`: 지금 라이트맵을 같은 UV로 나눠 보는 도구(내보내기 없음). 주의: 이 작업 트리의 `village_lmprep.blend`는
   배포된 라이트맵과 UV 배치가 달라(그 뒤 다른 굽기) 지금 맵에는 쓸 수 없었다 — 그래서 클라이언트 쪽 대체(마스크)를 만들었다.
